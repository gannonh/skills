# Herdr Delegate

1. Load and follow the `/herdr` skill. If it is unavailable, install it first:

   ```bash
   npx skills add https://github.com/herdrdev/herdr --skill herdr -y
   ```

2. Delegate the work to worker agents in uniquely named Herdr panes.
